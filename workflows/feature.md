# Feature workflow

Find or create the owning feature spec. Define the user-visible outcome and acceptance evidence with stable requirement IDs. Generate or update its plan and tasks, then identify contracts, persistence, integrations, UI, tests, operations, and documentation affected by the behavior. Implement a thin end-to-end slice before broadening it. Link requirements to tasks, code, tests, and verification in `traceability.json`. Verify the acceptance criteria before transitioning the spec to Implemented.
